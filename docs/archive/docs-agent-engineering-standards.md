# docs: 完善 Agent 工程规范

- 变更时间：2026-08-09 13:01 (+08:00)

## 变更理由

现有 `AGENTS.md` 主要约束格式化和变更记录，缺少从用户视角设计产品、控制系统复杂度、保持前端体验一致以及限制 Agent Git 操作权限的明确规则。规则不足容易使实现只关注技术可行性，或在没有独立授权时扩大提交、推送和远端操作范围。

## 变更内容

- `AGENTS.md`：新增产品与方案设计原则，要求优先考虑用户目标、最短操作路径和复杂度成本。
- `AGENTS.md`：新增前端交互规范，明确 HeroUI 优先、居中确认弹窗、紧凑布局和简洁文案等要求。
- `AGENTS.md`：新增后端方案与实现质量红线，禁止 trick、明显低效、无法长期维护和掩盖错误的逻辑。
- `AGENTS.md`：新增 Agent 操作与 Git 授权边界，区分修改、提交、推送、PR、发布和部署权限，并规范提交前检查及禁止操作。
- 关键取舍：规则采用可验证的行为和验收条件表达，避免只使用“优雅”“高质量”等无法执行的抽象要求。
